# 2026-10-05: CI's jobs are fewer, and the ruleset's required checks change with them

`.github/workflows/ci.yml` now has two quick jobs and the e2e shards:

- `lint-typecheck`: lint, typecheck, and the merge-commit check.
- `test-generated-build`: unit tests, `next build`, and the `convex/_generated` diff.
- `e2e (1..6)`: now in Playwright's own image, so no shard installs a browser.

**The ruleset has to change by hand, at the right moment.** It requires `typecheck`, `lint`,
`test`, `generated` and `build`, which this branch no longer reports. A pull request runs the
workflow from its merge with `main`, so:

1. Merge the pull requests below this one as usual, under the old checks.
2. Then, in the "No push to main" ruleset, replace those five required checks with
   `lint-typecheck` and `test-generated-build`.
3. Then merge this one and those above it.

Until step 2, this branch's pull request shows the old five as "Expected" and won't merge. After
step 2, any pull request still based below this one shows the new two as "Expected" until it is
rebased.

Watch on the first run:

- How long the e2e shards take to pull the image ("Initialize containers") against the 15-30s
  that `playwright install --with-deps` took. If the pull costs more, go back.
- The first run with no cached backend binary installs `unzip` with apt-get. Every other run
  skips that.
