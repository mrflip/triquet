hunt_git thread 8 (`20261005-viz`) adds `viz` to questions. It also adds `created_at`/`updated_at`
to every table of ours except `identings`; this is your Triggers recipe (convex-helpers
`Triggers`, `convex/stamping.ts`).

1. **After both PRs merge and deploy**, one run covers both threads (`notes/deploy.md`, the
   ledger rows for `20261005-orglabel` and `20261005-viz`):
   `./scripts/doppledo dev_aijanitor npx convex run migrations:runAll '{"dryRun": true}'`, then
   without the dry run.

     edited still reads as untouched.

   fallbacks dropped (`rows.orgFor`, `rows.vizOf`).
   - The stamps stay optional **for good**: a row is inserted first and the trigger stamps it
     after it lands.
   - `Stamps.of`'s `_creationTime` fallback stays, for rows the trigger never sees: dashboard
     edits, and anything written by the migrations.

Before merging, please check production for a **widgeting labelled `viz`, `created_at` or
`updated_at`**. These are now reserved, as `position` was in thread 2.
