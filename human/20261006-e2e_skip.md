# 2026-10-06: When e2e may be skipped, and a way to say so to `pnpm land`

* **The gate had no door.** `pnpm land` refused any branch without an e2e proof unless it
  changed only documents, so a script-only branch either ran the suite (about three minutes, and
  load on every other worktree) or was stopped. This thread adds `pnpm land --skip-e2e "<why>"`.
  It still wants a justify; a proof the branch already has stands over the reason; and the reason
  goes in the PR's Tests: line.
* **What it tells an agent at the moment of choosing.** With no proof and no reason, the refusal
  now says whether any path the branch changes is one e2e runs on or exercises (`e2eWatched` in
  `scripts/spine.ts`): unit tests, `.claude/`, the lint config and a short list of housekeeping
  scripts are not; everything else is, including a script nobody has listed and the harness
  scripts (`spine.ts`, `lanes.ts`, `convex_dev` and the rest). A skip over watched paths lands, with
  a warning, since you said the cost of a wrong call is a red CI and a question to the session.
* **The guidance** is `notes/git_hygiene.md`, *When e2e is not worth running*: why a run is not
  free, the usual skips, the exceptions to those (app code, harness scripts, mixed branches,
  anything a spec stands on), and the rule that confidence is the warning sign: say in one
  sentence why no spec could behave differently, and run e2e if it will not come.
  `.claude/agents/thread-worker.md` points at it.
* **Not done, yours:** `CLAUDE.md` step 3 of *Git* is what every session reads, and says `pnpm e2e`
  with no way out. Agents do not edit it on their own word. Suggested, after "(each failure repaired
  alone: `pnpm e2e:rerun`);": "`pnpm land --skip-e2e "<why>"` goes without it only where
  `notes/git_hygiene.md`, *When e2e is not worth running*, allows;".
* **Open:** the unwatched list is a judgment call about which scripts are housekeeping. It errs
  toward watched, so a wrong entry is a missed warning, never a missed skip.
