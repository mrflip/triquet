Clicking "Download Full History" delivers a single file ending in `.zip`, which a computer can expand into a file tree containing the current state of all your documents. That file tree is also what's known as a "git repo" (more polite than it sounds). By installing an application that works with a git repo, you can view each change, tiny and large; make copies at selected timepoints in the past; and compare the state of one or many documents between a pair of timepoints you name.
